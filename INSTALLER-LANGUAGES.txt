WoWInterpreter 2.1 installer languages

English:
- Inno Setup Default.isl

Simplified Chinese:
- Bundled installer-languages\ChineseSimplified.isl
- Full Inno Setup wizard UI translation: buttons, standard pages, errors,
  install/uninstall messages, progress/status text, etc.
- WoWInterpreter-specific AddOns selection messages remain defined in
  installer.iss [CustomMessages] for chinesesimplified.

The Simplified Chinese language file is vendored from the Inno Setup source
tree (is-6_7_1), where it is maintained as the Simplified Chinese translation.
Bundling it means the user's local Inno Setup installation does not need to
contain Languages\ChineseSimplified.isl.

Run build_release.bat. Final output:
installer\WoWInterpreter-2.1.4-Setup.exe
