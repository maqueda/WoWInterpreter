WoWInterpreter 2.1.1 - Installer path/runtime cleanup

Fixes the Inno Setup failure while compressing very deep Torch header paths.

Release process now:
1. Builds the tested PyInstaller application.
2. Removes Torch development-only content from the frozen runtime:
   - torch/include
   - torch/share/cmake
   - remaining .h/.hpp/.cuh/.hh headers under torch
3. Copies the runtime into release-stage/app.
4. Copies the addon into release-stage/addon.
5. Inno Setup packages only release-stage, not the raw dist tree.

Why:
Torch ships C/C++ development headers used for compiling extensions. They are
not required for WoWInterpreter's NLLB inference runtime and create extremely
deep paths that can break installer packaging.

Important:
The functional WoWInterpreter/Bridge/addon code is unchanged.
The full bundled Simplified Chinese Inno Setup translation is retained.
