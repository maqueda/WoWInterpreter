WoWInterpreter 2.1 - Release Build

Run:
    build_release.bat

The script now:
1. Builds the self-contained Windows application.
2. Verifies WoWInterpreter.exe exists.
3. Searches for Inno Setup 6:
   - PATH
   - Program Files (x86)
   - Program Files
   - LocalAppData Programs
4. If Inno Setup is missing, it stops with clear instructions.
5. If found, it compiles installer.iss automatically.
6. Verifies the final Setup.exe exists.
7. Opens Explorer with the finished installer selected.

Final distributable:
    installer\WoWInterpreter-2.1.4-Setup.exe

The installer itself remains bilingual:
    English
    Simplified Chinese (简体中文)

It asks the user to select their WoW Classic Era Interface\AddOns directory
and installs the addon into AddOns\WoWInterpreter.
